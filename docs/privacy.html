Privacy Policy

Last updated: August 25, 2026

This Privacy Policy explains how the Auto Video TikTok tool ("the Tool", "we", "us") handles data when generating and publishing video content to TikTok.

1. What We Process

The Tool processes the following data solely to generate and publish video content:

  • Text prompts and topics used to generate video scripts
  • Generated audio (text-to-speech voiceover)
  • Generated or sourced images used as video visuals
  • The resulting video file and caption/hashtags published to TikTok

2. What We Do Not Collect

The Tool does not collect, store, or process personal data belonging to TikTok viewers or third parties. The Tool does not access private messages, contact lists, or any TikTok user data beyond what is required to publish content to the developer's own authorized account via the TikTok API.

3. Third-Party Services Used

To generate content, the Tool sends processing requests to the following third-party services. Each provider processes data under its own privacy policy:

Service

Purpose

Groq

AI text generation (video script)

fal.ai

AI image / video generation

Microsoft Edge TTS

Text-to-speech voice synthesis

TikTok API

Publishing generated video content

No data processed by the Tool is sold to third parties or used for advertising purposes.

4. Data Retention

Generated video files and intermediate assets (scripts, audio, images) are retained only as long as needed to produce and publish the final video, and are stored locally or in the developer's own private infrastructure (e.g. GitHub Actions run artifacts, which are automatically deleted after a limited retention period).

5. TikTok Account Authorization

The Tool publishes content only to TikTok accounts that have explicitly authorized it via TikTok's official OAuth flow. Authorization can be revoked at any time by the account owner through TikTok's account settings.

6. Data Security

API keys and access tokens used by the Tool are stored as encrypted secrets (e.g. GitHub Actions Secrets) and are not exposed in source code or logs.

7. Children's Privacy

The Tool is not directed at children and does not knowingly process data related to children.

8. Changes to This Policy

This Privacy Policy may be updated from time to time. Material changes will be reflected by updating the "Last updated" date above.
