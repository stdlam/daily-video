What this is

Auto Video Producer is a personal automation tool built and operated by an independent developer. It generates short-form video content — a written script, a synthesized voiceover, visual assets, and burned-in captions — and publishes the finished video to the developer's own authorized TikTok account.

How it works

  • Script generation — an AI language model drafts a short video script from a given topic.
  • Voiceover — the script is converted to speech using a text-to-speech service.
  • Visuals — supporting visuals are generated or sourced for each scene.
  • Assembly — the voiceover, visuals, and captions are combined into a single video file.
  • Publishing — the finished video is reviewed and then published to the developer's own TikTok account via the TikTok API.

Who this is for

This tool is operated by a single independent developer for their own content creation workflow. It publishes only to TikTok accounts that have explicitly authorized it through TikTok's official OAuth flow.
